DST mod that automates Jimbo using maximin-like strategies.
[Steam page](https://steamcommunity.com/sharedfiles/filedetails/?id=3809582066)
[GitHub page](https://github.com/DortyTheGreat/turbo-jimbo-3)

Are you bad at poker? Now you can be bad even faster!

Adds various QoL features for the JIMBO minigame, and a Smart AI that plays (or hints) the mathematically best joker and discards using the real server scoring rules. All settings are in the in-game CONFIGS panel, reward chances in the ODDS panel.

This mod is an updated version of https://steamcommunity.com/sharedfiles/filedetails/?id=3467352009
